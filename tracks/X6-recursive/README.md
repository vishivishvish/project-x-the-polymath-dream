# X.6 — Recursive Self-Improvement Track

The grand loop: does what we learned across X.1–X.5 change *how* the agent learns, not just *what* it knows? Reviewed periodically, at the end of every tier — not per module.

Each review scans all four seedling logs ([X.3](../../curriculum/seedlings/X3-agent-seeds.md), [X.4](../../curriculum/seedlings/X4-paper-seeds.md), [X.5](../../curriculum/seedlings/X5-trading-seeds.md), [X.6](../../curriculum/seedlings/X6-recursive-seeds.md)), decides which seeds are worth promoting into real work, and records any resulting change to the agent's own learning code (X.3) or to how the curriculum sequences itself.
