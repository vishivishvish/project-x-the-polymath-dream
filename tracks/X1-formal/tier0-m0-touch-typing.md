# Tier 0 · Module 0 · Formal — Touch Typing

## Objective
Type without looking at the keyboard, at a target of 60+ WPM with under 3% error rate, using correct finger-to-key assignment (QWERTY home row standard).

## Curriculum
1. **Home row anchoring** — `ASDF` (left hand), `JKL;` (right hand), thumbs on space bar. Every other key is reached from this anchor.
2. **Finger-to-key map** — memorize the standard assignment (e.g. left pinky: `Q A Z 1`, left ring: `W S X 2`, etc.) before attempting speed.
3. **Row progression** — home row → top row → bottom row → numbers → symbols, each drilled to >90% accuracy before advancing.
4. **Speed building** — once accuracy is stable, drill common bigrams/trigrams (`th`, `ing`, `tion`) and full-sentence typing under time pressure.
5. **Real-text transfer** — apply to actual writing/coding (this repo's own markdown files count) rather than synthetic drills once past 40 WPM.

## Problem set
1. Type the home row 20 times without looking down. Record accuracy.
2. Time yourself typing a 200-word passage. Compute WPM = (characters typed / 5) / minutes. Compute error rate.
3. Identify your three most-error-prone letter pairs from a typing test report. Drill each in isolation for 5 minutes.
4. Repeat the same 200-word passage after one week of daily practice. Compare WPM and error rate deltas.

## Mastery checkpoint
Intermediate bar reached at: 60+ WPM, <3% error rate, zero keyboard glances, sustained across a 5-minute real-text passage (not a memorized drill).
