# X.5 — Agent Trading Track

An experimental testbed, deliberately separate from the production [algo-trading](https://github.com/vishivishvish/algo-trading) repo. The question here is not "does this make money" but "does the agent's learning-driven representation improve its own trading-relevant decisions over time." P&L/XIRR is tracked as one downstream metric among several, understood to take a long time to show real signal given the agent's current minimal representation.

Fires when a curriculum module plausibly improves decision-making under uncertainty. Promoted ideas come from [curriculum/seedlings/X5-trading-seeds.md](../../curriculum/seedlings/X5-trading-seeds.md).

Nothing implemented yet.
