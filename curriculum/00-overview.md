## Tier design logic

Simple → complex, Occam's Razor. Each tier is a prerequisite substrate for the next:

- **Tier 0 (Universal substrate):** everything below needs math, typing speed, and the ability to build software. Cheapest wins first.
- **Tier 1 (Data & compute core):** the substrate the agent itself runs on.
- **Tier 2 (Intelligence core):** directly drives X.3 (agent code) and X.4 (papers) — the fastest place the agent gets measurably smarter.
- **Tier 3 (Money & behavior):** feeds X.5 (trading) directly.
- **Tier 4 (Life & mind):** richest source of transferable X.2 axioms (biological learning systems).
- **Tier 5 (Physical & materials engineering):** needs Tier 0/2 math and Tier 4 sensorimotor concepts; good synthesis projects (robotics, drones).
- **Tier 6 (Frontier physics & space):** heaviest math prerequisites, least urgent for agent metrics.
- **Tier 7 (Hardest peaks):** capped at solid-beginner given the 10-year time budget — Quantum Computing, Quantum/Particle/Nuclear Physics, General Relativity.

## Spiral structure

- **Pass 1 (~Year 1):** shallow survey across every tier in order — vocabulary, core axioms, one toy exercise per field.
- **Pass 2+:** re-enter tiers in the same order at increasing depth, looping back to earlier tiers whenever a later tier's concept requires deeper grounding in an earlier one. Non-linear, but never skips the dependency order on first exposure.

## Cadence & mastery bar

**Cadence:** 15 minutes/day is the non-negotiable floor — keeps the streak, runs the agent, does spaced review of the Axioms Ledger. Deeper blocks (a weekend session) happen opportunistically whenever a new tier or module opens and warrants more than 15 minutes to get started. On the 15-min floor alone, 10 years ≈ 550 hours total — enough for broad intermediate coverage only if the daily floor actually holds; not enough to reach intermediate in every field without periodic deep blocks.

**Mastery bar**, per field:
- **Beginner** — knows the vocabulary and core axioms, can ELI5 the field.
- **Intermediate** — can solve textbook-level problems unaided, has built one working toy project, can read a paper in the field with real comprehension, can teach the topic to someone else.
- **Advanced** — can do original work in the field.

Target: intermediate everywhere except Tier 7 (capped at solid-beginner).

## The X.1–X.6 loop, per module

1. **X.1 Formal** — always. Rigorous treatment + problem sets.
2. **X.2 Conceptual** — always. ELI5 + axioms extracted into the [Axioms Ledger](axioms-ledger.md) + the module's **Seedling Log** (below).
3. **X.3 Agent** — conditional. Fires when the module teaches a transferable learning mechanism (state, update rule, feedback, memory).
4. **X.4 Paper** — periodic. Fires when a cluster of X.1–X.3 work accumulates into a real contribution.
5. **X.5 Trading** — conditional. Fires when the module plausibly improves decision-making under uncertainty.
6. **X.6 Recursive review** — periodic, end of each tier. Scans all four seedling logs, decides which seeds are worth promoting into real X.3 code, X.5 experiments, or X.4 paper threads; feeds the answer back into the agent's own learning code.

## Seedling Log (per module, mandatory, kept tight)

Every X.2 write-up ends with exactly four one-liners:

- **X.3 seed:** if this idea touched the agent's learning code, it would look like ___.
- **X.4 seed:** if this became a paper angle, the hook would be ___.
- **X.5 seed:** if this changed how the agent trades, it would be ___.
- **X.6 seed:** if this changed how the agent learns to learn, it would be ___.

Logged verbatim into [curriculum/seedlings/](seedlings/) under the matching track file. Most seeds are never promoted — that's fine.
