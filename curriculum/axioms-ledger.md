# Axioms Ledger

The running cross-domain distillation produced by X.2 (Conceptual Learning). Every module adds to this list only when it surfaces a principle that plausibly generalizes beyond the field it came from. Entries are never removed, only refined or cross-referenced as later modules deepen them.

Format per entry: **Axiom** — one-line statement · *first seen:* module · *reappears in:* fields where it's expected to resurface.

---

- **Automate the low-value bottleneck first.** If a skill is cheap to acquire, sits in the critical path of everything downstream, and has a hard ceiling on how much it can ever matter once mastered, front-load it. *First seen: Tier0-M0 Touch Typing. Reappears in: tooling/interface fluency, IDE shortcuts, lab instrument handling.*
- **Attention is a shared, depletable resource.** Two tasks compete for conscious attention even when only one looks "real" — offloading one to automaticity is a strict win for the other. *First seen: Tier0-M0 Touch Typing. Reappears in: cognitive load in ML training, control-loop attention in robotics, working memory in neuroscience.*
- **Representation precedes intelligence.** No update rule can outperform the ceiling set by its encoding. *First seen: Tier0-M1 Linear Algebra Foundations. Reappears in: every ML module, quantum state representation, econometric feature engineering.*
- **Similarity enables reuse of experience.** "Have I seen something like this?" is answerable the moment two situations can be encoded as vectors and compared. *First seen: Tier0-M1 Linear Algebra Foundations. Reappears in: attention mechanisms, kernel methods, energy-based models, quantum overlap.*
- **Normalization isolates signal from scale.** Raw magnitude is usually an artifact of volume, not meaning; the choice between L1 and L2 encodes what kind of structure you care about (direction vs. mass allocation). *First seen: Tier0-M1 Linear Algebra Foundations. Reappears in: softmax layers, embedding spaces, probability theory, signal processing.*
- **A transformation acts on coordinates, not on the space itself.** The map is not the territory. *First seen: Tier0-M1 Linear Algebra Foundations. Reappears in: coordinate changes in physics, basis changes in quantum mechanics, feature transforms in ML.*
